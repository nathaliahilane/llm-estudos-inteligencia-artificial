# llm-estudos-inteligencia-artificial
# Caderno de Estudos: Inteligência Artificial com LLMs

## Contexto e Objetivos

Este projeto tem como objetivo explorar o uso de Modelos de Linguagem (LLMs) como ferramenta de aprendizado em Inteligência Artificial.

### Objetivos:
- Entender conceitos fundamentais de IA
- Aprender a usar IA para estudar melhor
- Desenvolver pensamento crítico com respostas de IA
- Criar prompts reutilizáveis

## Engenharia de Prompts

### Prompt 1

**Pergunta:**
Explique o que é Machine Learning como se eu tivesse 10 anos.

**Resposta resumida:**
Machine Learning é uma forma do computador aprender observando exemplos, como identificar gatos e cachorros a partir de várias imagens.

---

**Análise:**
- O que funcionou: Explicação clara e didática  
- O que não funcionou: Ainda um pouco abstrato para uma criança  
- Como melhorei o prompt: Pedi exemplos mais próximos da realidade de uma criança  

Novo prompt:
"Explique o que é Machine Learning como se eu tivesse 10 anos, usando exemplos do dia a dia"

## Miniguia de Estudo

### Resumo

Inteligência Artificial é um campo da computação que busca criar sistemas capazes de simular inteligência humana.

Subáreas principais:
- Machine Learning
- Deep Learning
- NLP (Processamento de Linguagem Natural)

---

### Glossário

- **IA:** Sistemas que simulam inteligência humana  
- **Machine Learning:** Algoritmos que aprendem com dados  
- **LLM:** Modelos de linguagem de grande escala  
- **Prompt:** Instrução dada à IA  

---

### Prompts Reutilizáveis

- Explique [tema] de forma simples e técnica  
- Crie um resumo estruturado de [tema]  
- Liste os principais conceitos de [tema]
